# 内核矩阵（唯一口径）

> 这张表是**唯一**的内核支持说明。别在别的文档里重写一份，只引用这里。
> 最后一次按真机核对：2026-11-11。

## 一句话

**主包不绑内核**：`airsim-agent` / `airsim-mu300d` 是 Go 交叉编的静态件，页面 / rpcd / init.d 是纯脚本，
换内核不影响启动；安装脚本只对 `aarch64` 硬拦，内核版本一律「认一认、说清楚、继续装」。
**唯一跟内核有关的是语音驱动模块**，分两种来源，判据也不同。

## 判「语音到底行不行」的两种判据（别混用）

| 内核类型 | 判据 | 为什么 |
|---|---|---|
| 配件包内核（6.18 / 7.3） | `modules/<uname -r>/*.ko` 是否凑齐 **25 件** | 那 25 件是照 6.18.60 一套可用驱动点出来的清单，少一个就可能是残的 |
| 厂商内核（5.4 这类） | 读 `/sys/module/audio_reserve/parameters/missing`，必须 `0` | 厂商自己编的那套 `.ko` 名字、件数都跟清单不同（5.4 只有 24 个，名字也不一样），**按件数判会误报「缺 1 个」** |

额外确认（两条都满足才算真能用）：

```sh
cat /sys/module/audio_reserve/parameters/missing   # 期望 0
ls /dev/snd                                          # 期望有 controlC0/controlC1、pcmC0D0p ...
cat /proc/asound/cards                               # 期望看到 Loopback 与 sprdphone-sc2730
```

## 换内核怎么换

```sh
# 上游 release 里没有独立的 mu300-kernel-5.4.tar.gz，
# 5.4 就是那个默认名的 mu300-kernel.tar.gz（27,997,200 B，包内 Image 版本串 5.4.254-gb50db5b6224c）
MU300_RELEASE=v2026.11.02.1 \
MU300_KERNEL_BUNDLE=/tmp/mu300-kernel.tar.gz \
mu300-update kernel 5.4

# 6.18 / 7.3 同理，换掉 kernel 参数与包名
mu300-update kernel 6.18
```

- 两个环境变量都得给，否则脚本会去查最新 release，离线/省流量时会失败。
- 切完**必须重启**才生效；`/mnt/mu300-disk/boot/kernel` 是选择项，`uname -r` 是实际运行。
- 回退：`mu300-update rollback-boot`（要求 `prev.*` 还在；`prev.*` 空了就只能重新喂包）。
- 兜底：boot slot 给了 5 次失败机会，起不来会自己退到 Android。
