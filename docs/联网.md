# 联网（上网通道切换 + Wi-Fi 管理）

> 页面：`服务 → AirSIM → 联网`（`admin/services/airsim/net`）
> 代码：`overlay/f50/files/` 下 4 个后端 + 1 个页面，装完落在设备 `/usr`、`/www`
> 真机验证：6.18.60 与 5.4.254 双机通过（2026-11-11）

## 一、设计底线：USB 管理口地址不变

**`192.168.77.1` 全程不许跟着 Wi-Fi 走。**

- 不碰 `network.lan`（static `192.168.77.1`）
- 切换前的自检**只校结构**（`network.lan.ipaddr` 非空 + `br-lan` 端口恰好是 `usb0`），
  **不比对具体 IP** —— 管理地址是配置值不是常量，哪天换网段也不会把自己锁在门外
- 不碰 `br-lan` 的 `ports`（只有 `usb0`）
- 只操作三处：`network.wan`、`wireless.ap0`、`wireless.wwan0`

> 自己手动改 `lan` 那是自己的事；功能本身不会动它。

## 二、三种模式，状态只信 uci

| 模式 | `network.wan.disabled` | `wireless.ap0.disabled` | `wireless.wwan0.disabled` | 谁在出网 |
|---|---|---|---|---|
| 流量 `cell` | `0` | `1` | `1` | `sipa_eth0`（蜂窝） |
| Wi-Fi `wifi` | `1` | `1` | `0` | `wlan0`（STA 连外部 AP） |
| 热点 `ap` | `1` | `0` | `1` | 蜂窝（热点只是把自己的网分给手机） |

**判断当前模式就读这三个值，不要另外存一份状态**（另存必然不同步）。

```sh
ubus call airsim-net status
```

## 三、单射频的物理限制（必须照实说，不许美化）

| 限制 | 原因 | 页面怎么提示 |
|---|---|---|
| Wi-Fi 与热点**不能同时开** | 只有一个射频，`ap0` 与 `wwan0` 共用 `wlan0` | 卡片里写明「切过去手机断网几秒到十几秒」 |
| 只扫 5G 的 `36 40 44 48` | `radio0.band=5g`、`channels='36 40 44 48'`、`acs_exclude_dfs=1` | 「扫描只列这四个信道；2.4G 扫得到也连不上」 |
| 热点固定 36 信道、不做信道外扫描 | `noscan='1'`，出厂设置 | 「这是出厂设置，不要改」——**我们也不改** |
| Wi-Fi 模式下电脑通过 USB 只能管理 F50，不能出网 | `wwan` 不在任何 firewall zone，`nft` 里 `wlan0` 命中 0 | 红字写死，用户已明确**不修**这条 |

要是换了一台没这些限制的机器（`band_count=2`、`channels` 更多、`noscan=0`），后端按
`airsim-net-probe` 读到的真实能力走，页面会自动少提示几条 —— 判定看 `probe`，不写死。

## 四、Wi-Fi 五件事（都要有）

| 动作 | ubus 方法 | 关键细节 |
|---|---|---|
| 搜索 | `wifi_scan` | 单射频兜底：AP 模式下 STA 被禁用时，临时 `iw phy phy0 interface add scan0 type managed`，扫完 `ip link set down` + `iw dev scan0 del`，不留痕迹 |
| 选择 | 页面列表 | BSSID 取 iwinfo 第 5 列；`ESSID` 要剥掉一层引号；隐藏网络不列，页面给手动输入 |
| 输密码 | 页面表单 | `encryption` 键只认 `psk2 / sae / none`；非 `none` 时长度 8–63。命令行也认 `enc` 这个别名 |
| 连接 | `wifi_connect` | 已在 wifi 模式就只 `wifi reload` + `ifup wwan`，不重复整套切换 |
| 删除 | `wifi_forget` | **wifi 模式下拒绝**（「删掉会直接断网，先切回流量模式」）；永不回传密码，只给 `ssid / encryption / has_key` |

`wifi_saved` 只列已保存的，字段 `ssid / encryption / has_key` —— **不返回密码**。

## 五、切换的时序（页面别急着刷状态）

- `ifdown wan` 之后 VPN / IMS 那套要十几秒才稳
- `wifi reload` 连外部 AP 一般 8–15 秒
- 所以页面是「点一下 → 给 pending 反馈 → 轮询状态」，不是立刻断言成功

## 六、没有 LuCI 也能用（兜底）

页面挂了、LuCI 进不去，命令行照样能干活：

```sh
ubus call airsim-net probe                 # 本机无线能力
ubus call airsim-net status                # 当前模式 + 出口 + 已连 SSID/IP
ubus call airsim-net mode_set '{"mode":"wifi"}'
ubus call airsim-net wifi_scan
ubus call airsim-net wifi_connect '{"ssid":"XXX","encryption":"psk2","key":"********"}'
ubus call airsim-net wifi_forget '{"ssid":"XXX"}'   # 参数键是 ssid，必须在「流量」模式下才允许删

/usr/bin/airsim-netmode cell|wifi|ap      # 直接切模式（带基线自检与回滚）
/usr/libexec/airsim-net-probe             # 只读能力探测
```

## 七、文件与权限（装错一处页面就 403）

| 文件 | 目标路径 | 权限 |
|---|---|---|
| `usr/libexec/airsim-net-probe` | 同路径 | `755` |
| `usr/bin/airsim-netmode` | 同路径 | `755` |
| `usr/libexec/rpcd/airsim-net` | 同路径 | `755` |
| `usr/share/rpcd/acl.d/luci-app-airsim-net.json` | 同路径 | `644` |
| `www/luci-static/resources/view/airsim/net.js` | 同路径 | `644` |

> 权限 600 会让 uhttpd 报 `HTTP error 403 while loading class file`，页面直接打不开。这个坑踩过。

## 八、调试副本

设备上 `/tmp/net/` 留着一份可改副本，调 rpcd 时用两个环境变量指过去，不动正式文件：

```sh
AIR_SIM_PROBE=/tmp/net/airsim-net-probe \
AIR_SIM_MODE=/tmp/net/airsim-netmode \
/usr/libexec/rpcd/airsim-net
```

## 5.4 上的老坑：连热点的客户端没网

5.4 厂商内核上，fw4 生成的 flowtable 一旦含 `sipa_eth0`，整张防火墙表会加载失败，
`accept_to_wan` 变空、`forward` 又是 drop —— 结果就是"设备自己上网正常，连热点的手机没网"。
切到「流量」模式前先体检一下：维护页「客户端上网体检（5.4）」点体检，`suggest` 就先点修复，
`need_fix` 是已经坏了。命令行等价：`/usr/libexec/airsim-flowfix --check` / `--fix`。
6.18 / 7.3 上脚本自己 `skip`，不用管。
想恢复原样（比如要换内核、或不想留改动）：`/usr/libexec/airsim-flowfix --restore`，它把 `flow_offloading` 按回 1。
