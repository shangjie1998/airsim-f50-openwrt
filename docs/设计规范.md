# AirSIM 界面规范（玻璃元件库 v1）

视觉真源：`overlay/f50/files/www/luci-static/resources/view/airsim/glass.js`
（样式写在 JS 里不是图省事：`ui.css?v=` 的版本号跟着固件走，固件不换浏览器就一直吃旧文件。放模块里改一次生效一次。）

为什么要自己写、不引现成库：GitHub 上没有一套既适合 300 KB 级嵌入式页面、又能盖住 LuCI 主题的东西。
Open Props 只有 CSS 变量、没有元件；Pico/Water 风格写死；Bootstrap/Tailwind 要构建链；Shoelace/Konsta 是 Web Components，会把 LuCI 的 DOM 搅乱。
所以只借 Open Props 的 token 命名思路，元件层自建 12 个。

## 一、材质（两层变量，切主题整套换）

| token | 浅色 | 深色 | 说明 |
|---|---|---|---|
| `--g-surface` | `rgba(255,255,255,.62)` | `rgba(28,28,30,.62)` | 卡面底。反光只叠在上面，不参与底色调 |
| `--g-surface-strong` | `rgba(255,255,255,.80)` | `rgba(40,40,44,.80)` | 按钮/输入框/药丸底 |
| `--g-surface-solid` | `#ffffff` | `#141416` | 不支持 backdrop-filter 时的兜底 |
| `--g-tint` | `rgba(255,255,255,.12)` | `rgba(255,255,255,.08)` | 顶部高光带上限，浅色 ≤.12、深色 ≤.10 |
| `--g-edge` | `rgba(0,0,0,.10)` | `rgba(255,255,255,.14)` | 描边，按主题反向 |
| `--g-edge-top` | `rgba(255,255,255,.90)` | `rgba(255,255,255,.10)` | 顶部 1px 亮边 |
| `--g-shadow` | `0 12px 34px -14px rgba(0,0,0,.20)` | `0 18px 44px -16px rgba(0,0,0,.70)` | 常规投影 |
| `--g-shadow-up` | `0 22px 56px -18px rgba(0,0,0,.30)` | `0 26px 64px -18px rgba(0,0,0,.80)` | 悬浮/弹层 |
| `--g-blur` / `--g-sat` | `24px` / `180%` | 同 | 跟改造前一致，不是新增开销 |

间距只用 4 的倍数：4 / 8 / 12 / 16 / 24 / 32。

## 二、文字（苹果 Typography，1pt→1px）

| 用途 | 字号/行高 | 字重 | 颜色层 |
|---|---|---|---|
| 页面主标题 `.as-header h2` | 34 / 41 | 700 | `--ink` |
| 卡片标题 `.as-card h3` | 22 / 28 | 600 | `--ink` |
| 眉标 `.as-eyebrow` | 12 / 16，字距 .08em | 400 大写 | `--ink-3` |
| 正文 `.as-caption` 之外的段 | 15 / 22 | 400 | `--ink` |
| 说明 `.as-caption` | 13 / 18 | 400 | `--ink-2` |
| 备注/单位 `.as-facts dt`、`.as-field-label` | 12 / 16 | 400 | `--ink-2` |

## 三、12 个元件

| 元件 | 类名/函数 | 要点 |
|---|---|---|
| 卡片 | `.as-card` | 玻璃材质 + 顶部亮边 + 一个角落柔光斑 |
| 滑块开关 | `glass.switch(on, cb)` | button + 圆钮，`aria-checked` 表状态；开=钮在左轨蓝、关=钮在右轨灰 |
| 按钮 | `.as-btn` | 最小高 44，按下 `scale(.98)` |
| 分段控件 | `.as-tabs`（沿用) | 圆角 12，选中蓝底 |
| 输入框 | `.as-input` | 最小高 44，聚焦 2px 蓝环 |
| 状态药丸 | `.as-pill` | 12px/600，红绿必须带文字 |
| 消息条 | `.as-feedback` | 空内容整块隐藏，绝不留空蓝框 |
| 列表行 | `.as-row` | dt 12/16 说明色，dd 15/22 正文色，1px 分隔线 |
| 事实表 | `.as-facts` | 同上，两列对齐 |
| 提示块 | `.as-notice` | 圆角 18，浅底 + 语义色文字 |

## 四、易读性验收线（WCAG AA：正文 4.5:1，大字 3:1）

| 场景 | 实测近似 | 判断 |
|---|---|---|
| 浅色正文 `#1d1d1f` 于白玻璃 | 15:1 | 安全 |
| 浅色说明 `#6e6e73` 13px | 4.7:1 | 临界，所以浅色反光限 `.12` |
| 深色正文 `#f5f5f7` | 15:1 | 安全 |
| 深色说明 `#98989d` | 6.3:1，卡面被提亮到 `#2e2e30` 时 4.6:1 | 过线，所以深色高光只做 1px + 一个角落 |
| 深色最浅 `#6e6e73` | 3.5:1 | 原本不达标，禁止再抬亮卡面 |

## 五、性能红线（不做的三件事）

1. 不用 `mix-blend-mode`：每张卡会变成独立合成层，滚动时逐帧重合成，Safari 上最明显。
2. 不用 `mask`/`mask-composite` 画渐变描边：iOS Safari 的已知慢点，改用两条 inset 阴影。
3. 不用 SVG 位移滤镜（`feDisplacementMap`）：那是逐帧重算位移图，手机发热掉电，收益只是边缘一点折射感。

改造前后 `backdrop-filter` 半径一样（24px），所以增量只有几 KB CSS，静态页面渲染开销不变。

## 六、降级与动效

- `@supports not (backdrop-filter)` → 退回 `--g-surface-solid` 不透明底，老 iPad / 低端安卓不变糊。
- 动效统一 `.26s cubic-bezier(.32,.72,.28,1)`；`prefers-reduced-motion: reduce` 时全部关掉。
- 所有可点目标热区 ≥ 44×44（开关显示 56×32，行高补到 44）。
- 键盘焦点：`.g-switch:focus-visible`、`.as-btn:focus-visible`、`.as-input:focus` 都有可见环。

## 七、落地纪律

- 页面里不许出现十六进制颜色、不许写 px 字号；只准引用 token 和类名。
- 新元件先进 `glass.js`，页面只调用，不改材质。
- 视觉改了要四档视口验收：320 / 375 / 768 / 1280，深浅各一遍。

## 八、部署与缓存（这条最容易踩）

LuCI 给静态资源加的 `?v=` 是**固件版本号**，不是文件指纹。固件不换，`view/airsim/*.js` 改了文件浏览器照样吃旧缓存，普通刷新也没用。

- 样式与元件全在 `glass.js`，跟页面脚本同批更新，改一次生效一次；`ui.css` 只留旧页面兜底的布局规则，不再往里加东西。
- 改完部署后，验收前先硬刷（Mac 上 Cmd+Shift+R）；自动化验收时先 `fetch(url, {cache:"reload"})` 或带 `no-cache` 的同步 XHR 把缓存条目顶掉，再重载页面。
- 判断"到底有没有生效"不要看计算值就下结论：计算值对但像素不对是主题伪元素冲突；计算值和像素都对但控件没换，才是缓存没破。
