## 适用场景
同一上游衍生的两台设备各自维护「上游 src/ + 个性化 overlay/」，要把一端的自定义层搬到另一端，且两边打包目录结构不同、硬件参数不同时。

## 关键做法
1. 先把两边 overlay 摊平（去掉 `overlay/<机型>/` 前缀），再**归一化打包根**：一边是 `files/...`（插件包内根），一边是 `m8-pkg/luci/...`（自带包），去掉这些前缀后相对路径才可比；直接按原始路径求并集会全变成"单边"。
2. 分三档：样式/文案（css/js/ui/html/md）作可搬候选；含 ALSA 节点、采样率、卡槽、机型串的逻辑文件判为"需改写"；装机件（`pkg/`/`m8-pkg/`、`install.sh`、`*.init`、`modules/`）判"禁止搬"。
3. 样式资产要优先于打包路径规则判定，否则 `ui.css` 在 `m8-pkg/` 下会被一律打成"设备专属"，样式同步这条直接落空。
4. 只对两边都存在的文件算 diff 行数，这才是真待同步候选；单边存在的只是"对方有这东西"。
5. 光比样式不够，要把对方改动账本里的功能逐条列出来判：设备无关的（备份恢复、界面页）可搬；双卡专属、缺 URC 才加的轮询、大盘才需的日志裁剪一律不搬。

## 踩过的坑
- 首版分类规则把 `m8-pkg/` 前缀一律判"设备专属"，导致 `ui.css`/`ui.js` 被埋，shared 计数为 0，样式同步空转。修法：先按扩展名把样式资产单独判"可搬"，再有条件降级。
- 另一台出现的问题（心跳/拨号超时）不能推断本机也有：链路、卡槽模型、超时预算都不同，照搬会把真问题掩盖成超时。规矩是先在本机复现，复现不了记"未复现"。

## 可复用的产物或模板
只读比对脚本 `scripts/sync-m8.py`（`--only shared|rewrite|device`，`--m8/--f50` 指定路径），配套规矩 `docs/SYNC-M8-F50.md`，见 https://github.com/shangjie1998/airsim-f50-openwrt
