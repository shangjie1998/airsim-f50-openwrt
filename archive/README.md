# archive —— 只留档，不参与构建

**这里的东西一律不要引用、不要改、不要拿来当模板。** 需要现行版本请看 `dist/` 与远端 Release。

| 目录 | 装了什么 | 是否入库 |
|---|---|---|
| `旧整包/` | 老的整包目录快照（`airsim-f50-0.1.0.5-r23-6.18/`、`0.1.0.6`） | ❌ **已移出库**（2026-11-11）：每个 7 MB 级二进制 × 两个版本，只在本地与 Release 留副本 |
| `旧产物/` | 历史 `dist/*.tar.gz`（`0.1.0.2` ~ `0.1.0.19`、老 `audio-opt` / `bt-opt` 各版本） | ❌ **不在库**：`.gitignore` 挡掉了，只留本地与远端 Release，免得仓库越滚越大 |
| `5.4-pkg/` | 5.4 时代的设备补丁、修断网脚本、bundle 说明与校验和 | ✅ 在库（**只留文本与脚本**；整包解包目录与 tar.gz 已移出，去 Release 下载） |

## 为什么旧产物只留本地

1. 每个包 5~6 MB，二十来个就是一百多兆，克隆一次全背上；
2. 它们**每一个都在 GitHub Release 上有正式副本**，需要就按版本号去下；
3. 真正的价值是「当时怎么打的」，那部分已经在文档和 `git log` 里，不在二进制里。

## 找老包的正确姿势

```sh
# 按版本挑：releases/tag/v0.1.0.<N>-r<NN>-<any|6.18>
https://github.com/shangjie1998/airsim-f50-openwrt/releases
```

本地 `archive/旧产物/` 只是顺手留的一份，**删了不影响任何东西**。
