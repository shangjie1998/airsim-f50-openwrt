# 修断网.sh 为何归档在这里

`修断网.sh` 是 **5.4.254 厂商内核**时代的补丁脚本：它把 `firewall.@defaults[0].flow_offloading` 设为 `0`，
让 fw4 不再生成 flowtable，从而绕开"flowtable 含 `sipa_eth0` 导致整张防火墙表加载失败 → 客户端无互联网"。

**6.18 线不再使用，也不再随包提供。** 2026-11-09 在设备（内核 `6.18.60`）实测 `flow_offloading=1`：

```
flowtable ft { hook ingress priority filter; devices = { "sipa_eth0", "usb0", "wlan0" } }
accept_to_wan sipa_eth0 count: 2
ping 223.5.5.5: 0% packet loss
```

即冲突在 6.18 上不存在，开回流卸载反而降低转发 CPU 占用。若将来换回 5.4（`archive/5.4-pkg/`），
再把这个脚本拷到设备上跑 `--check` / `--fix`。详见 `docs/5.4/F50-数据联网修复.md`。
