# 验证记录（2026-11-08，同一份包在两个内核上各跑一遍）

## 5.4 内核 —— 可用（含语音）

| 项 | 命令 | 实测 |
|---|---|---|
| 内核 | `uname -r` | `5.4.254-gb50db5b6224c` |
| 服务 | `/etc/init.d/airsim status` | `running`（3 个进程） |
| 音频 | `ubus call airsim status` | `audio_available: true` |
| 显示名 | `ubus call airsim status` | `"product": "AirSIM for F50"` |
| 包版本 | `head -1 /usr/lib/airsim/MANIFEST` | `0.1.0.2-r22-f50`（当时那版） |
| mDNS | Mac `dns-sd -B _airsim-vowlan._tcp` | `AirSIM-F50-0p0JKELA`，TXT `device_name=AirSIM F50` / `model=F50` / `agent_kind=mu300` |

设备当时没插卡，所以只验到"插件起得来、音频可调用"，通话本身未复验。

## 6.18 内核 —— 能跑，但没语音

| 项 | 实测 |
|---|---|
| 内核 | `6.18.60`（模块 2958 个） |
| 服务 | `/etc/init.d/airsim status` = `active with no instances`（prepare 的音频预检过不去） |
| 手动起 daemon | 正常，日志首行 `F50 plugin ready; pairing port 8580` |
| `audio_available` | `false` |
| 显示名 | 仍为 `AirSIM for F50` / mDNS `AirSIM-F50-0p0JKELA` |

结论：6.18 上装得进、跑得动、名字对，但打电话没声音。**本包只对 5.4 负责**。
